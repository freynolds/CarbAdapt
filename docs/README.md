# docs

Architecture decisions and runbooks. Empty apart from this note.

## What goes here

- ADRs when a decision is accepted (API shape, theme wiring, where the worker runs).
- Runbooks for local reset, webhook replay, and deploy, once those procedures exist.

## What must NOT go here

- The product plan as a substitute for code comments that belong next to the package they describe.
- Secrets, fixture data, or screen markup.

## Milestone

The first ADR lands when a choice in the build plan's open list is accepted. Nothing is written here in the scaffold step.
